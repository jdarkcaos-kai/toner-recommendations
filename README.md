# Toner recommendations

## ID
P-0002

## Template base
landing_mvp

## Problema
Los usuarios tienen dificultades para encontrar el toner adecuado para sus impresoras, lo que puede resultar en compras incorrectas y desperdicio de dinero.

## Audiencia
Propietarios de impresoras, pequeñas empresas, y usuarios domésticos que buscan soluciones rápidas y efectivas para elegir toner.

## MVP
Una herramienta web que permite a los usuarios ingresar el modelo de su impresora y recibir recomendaciones personalizadas de toner compatibles.

## Stack sugerido
- React
- Node.js
- MongoDB

## Roadmap
- Investigar modelos de impresoras y sus toners compatibles
- Desarrollar la interfaz de usuario y la lógica de recomendación
- Lanzar la herramienta y recopilar feedback de usuarios

## Riesgos
- Falta de datos precisos sobre compatibilidad de toners
- Baja adopción por parte de los usuarios
- Competencia de herramientas similares ya existentes
